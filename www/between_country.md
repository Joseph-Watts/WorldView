### Between Countries Chart

These charts allow comparison of the responses to the same question from two different countries.

For the bar charts, the x-axis is labelled with the "levels" corresponding to the possible responses for each question. Sometimes both questions will have the same responses, other questions will have different responses. The width of the bar is irrelevant - the bars size to fit the space, so a question with 3 responses will show a having wider bars.
The y-axis represents the frequency count, showing the number of individuals per response type. Note that the y-axis also resizes to fit the space, so you need to check the scales carefully as they may differ.
