# WorldView Project

## Description & Objective

The goal of this project is to create an environment for people with limited coding skills to use and visualise data from the World Values Survey to test predictions and hypothesis. The World Values Survey ([WVS](https://www.worldvaluessurvey.org)) is an international research program devoted to the scientific and academic study of social, political, economic, religious and cultural values of people in the world.

This app allows students to understand data gathered across multiple countries, cultures, and moments in time.

## Target user

Psychology students, primarily at the University of Canterbury, Christchurch, New Zealand.
