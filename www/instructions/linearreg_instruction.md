## Linear Regression 

Predict responses to one survey question using one or more other survey questions as predictors.

Use the model output to interpret the direction and strength of each predictor, assess overall model fit, check diagnostic plots, and visualize predicted values against the observed response distribution.

Outcome variables must be numeric, including integers, or ordered factors. When ordered factors are selected as outcomes, they are converted to the numeric values shown in the Codebook.

Missing data (NA) are removed from the data used in this analysis.
