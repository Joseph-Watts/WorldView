## Human Development Report (HDR) Data Sources

This application uses statistical data from the **Human Development Reports (HDR)** published by the **United Nations Development Programme (UNDP)**.


### Accessing the original HDR tables

The original HDR statistical tables can be viewed and downloaded directly from the UNDP HDR Data Centre:
`https://hdr.undp.org/data-center/documentation-and-downloads`



Each table is provided as a Microsoft Excel file and includes full metadata and methodological notes.

The six tables were also provided into a single multi-sheet Excel workbook available for download.
