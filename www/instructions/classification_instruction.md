## Classification Analysis Instructions

1. **Select Target Variable**: Choose the categorical variable you want to predict
   - Country: Predict respondent's country
   - Gender: Predict gender (Male/Female)
   - Education Level: Predict education category
   - Religiosity: Predict religious category

2. **Select Predictor Variables**: Choose up to 10 survey questions as predictors

3. **Select Countries**: Limit analysis to specific countries (recommended for country prediction)

4. **Adjust Sample Size**: Reduce for faster computation with large datasets

5. **Output Interpretation**:
   - Model Summary: Shows overall accuracy and model parameters
   - Confusion Matrix: Compares actual vs predicted classes
   - Variable Importance: Shows which questions best predict the target
   - Prediction Plot: Visualizes classification results using PCA
