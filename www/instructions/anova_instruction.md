## ANOVA

This ANOVA model uses country as the predictor variable and the selected variable as the outcome variable. It tests whether people from two or more countries differ in their responses to that variable.

Only numeric or ordinal variables, including integers, can be selected as outcome variables in an ANOVA. Simple unordered factor/categorical variables cannot be used as outcomes.

You can identify where specific differences occur using post-hoc tests, and you can check model assumptions using diagnostic plots.

One minor note: if the outcome is strictly ordinal with only a few response categories, ANOVA may be less appropriate than an ordinal model, but it is often used for Likert-type scales when treated as approximately continuous.
