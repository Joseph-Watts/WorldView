WorldView World Map topic-grouping update
========================================

Copy the contents of this package into the ROOT of your current WorldView
repository, preserving the folder structure, and replace the existing file.

REPLACE:
  worldview_deployment/assets/step28-enhancements.js

Change
------
The World Map variable selector is now grouped under the same WorldView topic
headings used by the other analysis pages.

This update also makes variable grouping robust to controls that populate
asynchronously after page load, which was why the World Map selector could
remain as one flat list even when other pages were grouped correctly.

Testing
-------
1. Run:
     servr::httd("worldview_deployment")
2. Hard-refresh with Ctrl+F5.
3. Open Visualisations > World map.
4. Open the Variable dropdown and confirm variables are nested under topic
   headings.
5. Check Phylogeny and the other variable selectors remain grouped normally.
6. Run /validation.html.

No WVS data rebuild is required.
